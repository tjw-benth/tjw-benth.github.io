# tjw-benth.github.io

Personal academic website for Tom Williams — marine benthic ecologist at Åbo Akademi University.

Live at **https://tjw-benth.github.io**

---

## Stack

Plain static HTML/CSS/JS. No framework, no build step. Hosted on GitHub Pages.

- Template: [HTML5 UP Solid State](https://html5up.net/solid-state)
- Icons: Font Awesome 6 (self-hosted)
- Analytics: [GoatCounter](https://www.goatcounter.com/) (privacy-respecting, no cookies)
- Map: Leaflet 1.9.4 (self-hosted)
- CV gate: Cloudflare Turnstile + Worker

## Local dev

Open any `.html` file directly in a browser — no server needed for most changes.

The CV download modal bypasses Cloudflare verification on `localhost` automatically.
